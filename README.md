# 🍀 Lucky Lucky

**한국어** · [English](README.en.md)

점심 5분 두뇌 서바이벌. 각자 폰이나 PC로 같은 방에 들어와 함께 문제를 풉니다. 최대 50명.

▶ **플레이: https://luckylucky.lunchtime.workers.dev**

## 소개

- 한 사람이 방을 만들고(1R·2R·3R), 나머지는 QR 이나 코드 4자리로 들어옵니다. 방장이 시작.
- 라운드마다 게임 3종이 무작위로 나오고, 게임마다 문제가 점점 어려워집니다. 문제는 매판 코드로 새로 만듭니다.
- 두뇌 게임: 수열 · 도형 행렬 · 숨은 규칙 · 거짓말쟁이 · 줄 서기 · 요일 계산 · 암산 · 연산자 채우기 · 다른 하나 · 시계 각도 · 과일 방정식 · 저울 · 개수 세기 · 블록 세기 · 돌려 보기 · 잠깐 기억 · 네모 찾기
- 심리전: 소수파 생존 · 평균의 ⅔ · 눈치 줍기

## 규칙

- 코인 10개로 시작합니다.
- 제한 시간 앞 절반 안에 맞히면 +3, 늦게 맞히면 +2, 틀리면 −1.
- 2라운드 꼴찌는 ⚠ 위기. 마지막 라운드는 코인 베팅(위기인 사람은 절반 이상 걸어야 함).
- 최종 꼴찌는 「☕ 오늘 커피 당번」.

## 실행해 보기

```sh
npm install
npm run dev        # http://127.0.0.1:8793
```

주소에 `?games=rect,mat,liar` 를 붙이면 게임을 골라 시작합니다(시험용).

## 코드 구조

| 경로 | 내용 |
|---|---|
| `server/worker.js` | Cloudflare Worker + Durable Object `Room`(방 번호마다 하나)이 게임을 진행 |
| `public/js/puzzles.js` | 문제 생성기(서버와 화면이 같이 씀) |
| `public/js/app.js` | 참가자 화면(폰·PC 같음) |
| `public/vendor/` | qrcode-generator(MIT) · jsQR(Apache-2.0) |
